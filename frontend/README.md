# 旭日学堂 · Vue 前端

Vue 3 + Vue Router + Vite。企业培训系统前端，沿用主蓝 `#003f98`、深蓝 `#00274c` 和黄色 `#ffcb0b`，配套仓库中的 `sys/` SSM 后端。

## 最快查看：不安装任何开发工具

下载整个仓库后，打开根目录 `demo/`，双击 **旭日学堂-离线演示.html**。它是构建生成的单文件，已内嵌脚本、样式、图标和30秒示例视频，不需要 Node.js、Maven、Tomcat、SQL Server 或网络。

按你目前的目录，文件位置是：

```text
D:\AAA总经办\文档\总经办工作\部署\--main\--main\demo\旭日学堂-离线演示.html
```

建议使用近期版本的 Edge 或 Chrome。离线演示的数据保存在当前浏览器；“运行与账户设置”可重置。浏览器禁止文件页面存储时使用当前页面内存，刷新将恢复初始状态。

本次环境禁止浏览器访问file协议，未直接实测双击；已通过HTTP加载同一文件后断网核验内嵌视频及交互。如果公司也限制本地HTML，请使用公司允许的HTTP开发预览方式，详见 [验证说明](../demo/前端验证说明.md)。

离线演示不能替代数据库和真实模型联调。它明确标记演示状态，课程助手返回带有演示标识的固定示例；不会伪装成已经调用AI。右上角身份选择仅在演示模式出现。

## 源码开发

需要 Node.js 22.12+ 或更新的受支持版本。Node.js 可以按公司政策使用Windows ZIP免安装版。已有 Node.js 时，在 PowerShell 执行：

```powershell
Set-Location -LiteralPath "D:\AAA总经办\文档\总经办工作\部署\--main\--main\frontend"
node -v
npm.cmd ci
npm.cmd run dev
```

使用 `npm.cmd` 可避免 PowerShell 将 `npm` 解析为被执行策略限制的ps1脚本。打开终端输出的本机地址，通常是 `http://127.0.0.1:5173/`。不要把远程开发环境的127.0.0.1地址当成你电脑上的预览。

```text
npm test          # 演示适配器和关键规则测试
npm run build    # 构建dist并生成单文件离线演示
npm run preview  # 预览dist（仅静态预览，不包含开发代理）
```

Windows也可将上述命令中的npm替换成npm.cmd。

## 对接SSM后端

1. 更新仓库后，重新构建 `sys` 并部署到 Tomcat 10.1。本次补充了只返回本讲师所属考试（管理员可查看全部）的 `GET /api/teaching/exams`，旧后端没有此接口。
2. 开发服务器 `/api` 默认代理至 `http://127.0.0.1:8080/training/api`。Tomcat不同端口时，启动前设置 `TRAINING_API_TARGET`。
3. 在“运行与账户设置”切换后端模式，API路径保留 `/api`；使用实际员工账号登录。
4. 后端连接失败、未分配课程、模型未配置或权限不足时，前端明确展示对应状态，不自动用演示数据填充。

例如Tomcat在8081：

```powershell
$env:TRAINING_API_TARGET="http://127.0.0.1:8081"
npm.cmd run dev
```

所有请求携带Bearer令牌；登录令牌仅保存在当前标签页的sessionStorage。视频只使用后端生成的限定单文件、15分钟有效的播放凭证，临近到期刷新，登录令牌不会拼到视频URL。

正式部署建议将 `dist/` 放到同域静态服务器，反向代理 `/api` 到 Tomcat `/training/api`。如果静态前端直接与Tomcat同域、使用 `/training/api`，在设置中填写该路径。前端采用hash路由，不需要后端为每个页面配置路由回退。

双击离线HTML不能切换后端模式；实际联调需通过HTTP运行。`npm run preview`没有Vite开发代理，需要同域代理配置或使用后端API的同域路径。

## 学习计时

前端每10秒及播放/暂停/拖动/结束时按连续seq串行发送事件；重试保留原事件和seq，不跳号。缓冲和页面隐藏暂停计时，非1倍速会恢复1倍速。跳播提示并留事件，频繁跳播和多开由后端形成预警。网络错误暂停播放并展示重试，用户离开时提示未同步记录。

演示模式用本地数据模拟这些规则，不具备数据库原子锁、可信服务端时间或后台定时收卷能力。正式完成率、有效时长、考试资格与成绩以SSM服务端为准。考试期间页面切屏会发送风险事件，不能宣称仅靠网页就可以完全防作弊。

## 数据和当前边界

- 页面显示的组织、员工、课程和指标均来自所选模式的数据；演示使用虚构样例，不代表公司真实培训情况。
- 排程输入按北京时间转换UTC。数据库datetime2的无时区值按UTC解释，显示为Asia/Shanghai。
- 课程列表沿用后端每页100条、考试管理沿用200条上限，本版面向首轮演示和联调；大规模管理列表仍需补齐分页。公司明细支持200条翻页，CSV走后端完整分批导出。
- 演示模式的文件选择仅用于浏览器本次预览，刷新后展示内置示例视频；正式上传与持久化使用后端文件服务。
- xlsx下载/导入只在后端模式可用，演示中使用选题组卷体验。Word/PDF自动解析、随机抽题、直播、外部SSO不在本版内。
- 已完成构建和浏览器核验不等于真实SQL Server/AI联调。当前未配置公司的数据库或模型密钥，未进行真实业务数据验证。
