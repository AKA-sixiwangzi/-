# 旭能学院六项培训功能使用说明

更新日期：2026-11-17。岗位继续固定为专业岗、管理岗、综合岗；角色为普通员工、内训师、部门负责人、组织发展部。

## 开始体验

使用本次更新后重新构建的 `旭能学院-离线演示.html`，在演示身份中切换普通员工、内训师和组织发展部。演示数据是当前浏览器中的虚构样例，不写入公司的培训数据库。浏览器允许时可以直接打开HTML；若公司禁用本地HTML，使用公司允许的HTTP预览方式。

演示不能代替真实登录、SQL Server持久化和持续运行的定时服务。真实部署的升级步骤见 [培训流程V1.3](../sys/docs/培训流程V1.3.md)。本次检查结果见 [验证说明](六项培训功能验证说明.md) 和 [测试结果](六项培训功能测试结果.json)。

## 1. 新建员工，自动生成账号

1. 切换组织发展部，进入“组织与人员”，点击“添加员工”。
2. 填姓名、部门、三种固定岗位之一及职级，保存后查看账号回执。
3. 将本次显示的账号与临时密码交给该员工。临时密码只在此次创建回执展示，员工列表不能再次查看原密码。
4. 真实后端登录时，新员工会被引导至设置页先改密码，改好后用新密码重新登录。演示身份切换用于体验界面，不模拟真实账号登录的全部安全流程。

## 2. 创建视频或纯资料课程

1. 任意员工进入“我的课程创作”，创建课程草稿。
2. 可添加视频章节，也可只添加资料。资料支持文字/TXT、PDF、PPT/PPTX或网页链接，填写资料名称并按需勾选“必读”。
3. 纯资料课程至少有一份必读资料；提交后由另一位组织发展部人员审核发布。
4. 课程分配给员工后，员工从“我的课程”打开资料，阅读后主动确认。

PDF可按浏览器能力预览或下载；PPT/PPTX需下载后用Office或兼容软件打开，本版不转换成在线幻灯片。网页链接会打开外部网页。文字资料可输入正文，也可选择TXT附件。

所有视频仍按真实有效播放规则完成，拖动进度条不会补齐观看时长。必读资料确认和视频时长是两种记录；选读资料不影响完成。课程助手使用录入的文字正文，不自动读取PDF/PPT或网页全文。

## 3. 创建培训计划并设置负责人和提醒

1. 组织发展部进入“计划管理”，新建计划，填写开始和截止时间。
2. 选择培训课程、固定参训员工和可选考试，指定启用员工为负责人；未指定时由创建人负责。
3. 默认截止前72小时开始、每24小时重复提醒，并向负责人推送结果，可按实际需要修改。
4. 保存草稿后发布，员工会获得计划任务。课件和作业在各课程中配置，计划关联考试应覆盖相应课程前置条件。
5. 负责人或组织发展部可修改提醒规则，也可点击“执行提醒”。转交负责人须由组织发展部操作。

提醒和结果发送到“消息中心”，相同周期、相同结果不会重复发送。真实后端约每小时检查已发布计划；演示仅在页面操作时模拟，不会在关闭页面后自动运行，也没有邮件推送。

## 4. 对简答题逐题阅卷

1. 员工参加包含简答题的考试并交卷，个人结果显示“待人工阅卷”。
2. 有权负责该考试或试卷的内训师，或组织发展部，进入“题库与考试”的阅卷区域。
3. 查看每题答案和参考答案，填写该题分值范围内的整数，可补充评语；空白简答也需要明确填0分。
4. 逐题保存，全部评分后才产生最终总分和通过结果。

不能批改自己的考试，已批改题目不能重复覆盖。未评完时不显示最终通过，不用部分题目得分冒充总成绩。

## 5. 安排线下培训，记录出勤与成绩

1. 组织发展部或内训师进入“线下培训”，点击“安排线下培训”。
2. 填名称、地点、起止时间和授课内训师，按需关联计划/课程，勾选参加员工。
3. 培训开始后，授课内训师或组织发展部打开“出勤与成绩登记”，逐人选择出勤、缺席或请假，可填成绩和备注。
4. 填写登记或更正原因后保存；未操作的人员保持待签到，不自动记出勤。
5. 员工在“我的培训成果 → 线下参训”查看本人记录。

只有标记出勤且场次已结束才计线下学时。线下成绩、备注及更正原因保留记录，线下学时独立于视频有效播放时长。内训师只能安排本人授课及自己课程的学员。

## 6. 按计划跟进教学成果

1. 内训师从“授课工作台”或侧栏进入“计划跟进看板”；组织发展部可查看全公司计划。
2. 选择计划，再选择某位员工，查看其课程、配套资料、考试和作业结果。
3. 待人工阅卷、待作业评价分别显示；计划关联考试另有汇总，线下培训展示对应时间、地点及内训师。
4. 被指定为负责人的普通员工，可从“培训计划”列表进入“计划跟进”及“提醒规则”，无需增加管理角色。

内训师只看本人课程，负责人查看自己所负责的整项计划；看板权限不会自动赋予课程编辑、无关考试阅卷或他人线下出勤登记权限。

## 正式系统更新

离线演示不要求公司的建库权限。正式后端使用现有培训库，先确认02、03、04增量脚本已执行，再请有权限的数据库管理员执行 `sys/database/05-training-workflows.sql`，之后更新WAR。不要在已有数据的库上重跑01全量建表；旧账号、学习和成绩保留，旧资料默认选读。

本说明描述本版交互和规则，不表示真实数据库迁移、Office文件打开或长期定时通知已经完成部署验收。
