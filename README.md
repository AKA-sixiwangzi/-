# 旭能学院

企业内部培训系统，后端使用传统 SSM（Spring、Spring MVC、MyBatis），数据库使用 SQL Server，前端使用 Vue 3。蓝色 `#003f98`、深蓝 `#00274c` 与黄色 `#ffcb0b` 组成统一视觉。

2026-11-17 更新范围：员工自动账号与首次改密、多格式及纯资料课程、培训计划负责人和站内提醒、简答题逐题人工阅卷、线下出勤与独立学时、讲师及负责人计划跟进看板。岗位仍固定为专业岗、管理岗、综合岗；角色仍为普通员工、内训师、部门负责人、组织发展部。

最新说明见 [培训流程 V1.3](sys/docs/培训流程V1.3.md) 与 [六项功能使用说明](demo/六项培训功能使用说明.md)。已有数据库先确认02、03、04已执行，再由有权限的数据库管理员执行 [05增量脚本](sys/database/05-training-workflows.sql)，之后部署新版 WAR；保留已有账号和学习记录，无需新建数据库。新库使用最新01建表脚本。

本次验证结果以 [六项功能验证说明](demo/六项培训功能验证说明.md) 和 [测试结果](demo/六项培训功能测试结果.json) 为准；下方历史测试数字与截图对应其标注版本，不能代表本次更新已完成实库联调。

当前提供前后端首版，支持员工兼任讲师、课程审核、岗位成长路线、培训计划、有效播放校验、课程关联考试、预警处理记录，以及课程问答和 AI 出题草稿接口。

## 没有数据库，也可以先体验

下载整个仓库，解压后双击 **`demo/旭能学院-离线演示.html`**。无需安装 Node.js、JDK、Maven、Tomcat 或数据库，页面和30秒示例视频均已内嵌。右上角可以体验员工、讲师、管理员和独立复核管理员。

演示数据仅保存在浏览器，明确标记为演示，不作为正式培训结果。课程问答和AI出题返回带有说明的固定示例；真实模型需要在后端配置。

## 源码运行

后端：在 `sys` 目录使用完整 JDK 17 或 21 执行 `mvn clean verify`，将生成的 WAR 部署到 Tomcat 10.1。真实业务需要初始化SQL Server。

前端：Node.js 22.12+，在 `frontend` 目录执行 `npm ci`、`npm run dev`，默认演示模式。后端就绪后在页面设置切换模式，开发代理默认指向 `localhost:8080/training/api`。Windows PowerShell可使用 `npm.cmd` 执行命令。

最新V1.3后端测试为215项通过、1项SQL Server实测跳过；前端52项通过，另行核验员工自动账号、多格式资料、首次改密、人工阅卷、计划提醒、线下记录与讲师计划看板。数据库实际联调和真实AI调用尚未验证。数据库密码、初始管理员密码和模型密钥通过部署环境变量配置，仓库仅保留配置模板。
